## Purpose

系统评估 PostgreSQL BM25 插件路线与 ReqFlow 当前检索架构的配合情况，重点验证中文环境兼容能力、执行效率、准确率和运维复杂度，形成是否采用某个 BM25 插件作为后续 runtime option 的证据化决策。

## Scope Boundary

- 本 milestone 是评估/PoC，不直接把 BM25 切为默认 runtime。
- 保留当前 native PostgreSQL FTS fallback + pgvector + RRF-style fusion baseline。
- 候选插件必须在隔离 runtime / alternate compose / candidate image 中验证，不覆盖 MS-13 默认 compose 路径。
- 不删除现有 Docker volumes、uploads、model cache 或数据库状态。
- 不执行生产数据迁移。
- 不引入外部托管搜索服务或非 PostgreSQL 搜索服务。
- 不改变 AI provider secret 管理策略。

## Design Decisions To Carry Forward

1. BM25 只能来自可验证 PostgreSQL extension/runtime candidate，不能把 PostgreSQL native FTS 写成 BM25。
2. 每个 candidate 必须独立证明 extension availability、`CREATE EXTENSION`、index DDL、query probe、中文 tokenization behavior 和 rollback boundary。
3. 中文评估必须覆盖纯中文、混合中英、业务缩写、同义词/近义表达、长文档片段、zip path/source citation 场景。
4. 性能指标至少包含 index build time、query latency、candidate count、EXPLAIN/plan evidence 和资源观察。
5. 准确率评估必须和 native FTS fallback、pgvector/hybrid fusion baseline 对比，不能只展示单插件成功样例。
6. 最终决策可以是 adopt / defer / reject；不以“插件能启动”作为默认启用依据。

## Completion Signals

1. BM25 插件候选矩阵记录 runtime 版本、PostgreSQL 版本、license/distribution、preload requirements、extension availability 和 operational risk。
2. 中文 benchmark harness 能重复运行并生成可比较结果。
3. 至少一个 candidate runtime 被完整 PoC，或所有 candidate 均被证据化判定为当前环境不可行。
4. 中文兼容评估记录 tokenizer/segmentation 行为和失败样例。
5. 性能/准确率报告对比 BM25 candidate、native FTS fallback 和现有 hybrid retrieval。
6. 最终报告给出是否进入后续“BM25 runtime enablement” milestone 的建议。

## Acceptance Criteria

1. `npm run lint`, `npm run test`, `npm run build` pass or have explicit not-applicable evidence.
2. Candidate runtime tests do not mutate MS-13 default runtime or delete existing volumes/cache.
3. Extension readiness probes distinguish installed/available/missing/preload-required states.
4. Chinese evaluation includes repeatable fixtures and quantified results.
5. Performance report includes local environment notes and avoids overclaiming production performance.
6. Docs do not claim BM25 active behavior unless a candidate runtime passes the defined gates; even then default runtime switch remains separate approval.

## Milestone Gate Design

- black_box: operator can run BM25 candidate evaluation commands and obtain Chinese retrieval quality/performance evidence.
- white_box: candidate runtime availability, extension creation, tokenizer behavior, index/query probes, benchmark data, and fallback comparison are all recorded.
- anti_cheat: 不允许只证明 container 启动就宣称 BM25 可用；不允许只用英文样例代表中文兼容；不允许只展示单个成功 query；不允许把本地小数据性能写成生产结论；不允许默认替换 runtime。
