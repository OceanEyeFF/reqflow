3. CI 使用仓库现有脚本，不降低 `lint/test/build` 质量门。

5. AI Brief 必须说明人工确认、知识库来源、OpenAI 接入边界和无 PG 依赖。
6. 所有改动继续遵守 worktree 工作流。

## Milestone Gate Design

- black_box: GitHub 上能看到最新 `develop`，CI workflow 已运行并记录结果。
- white_box: workflow、package scripts、上云边界文档、AI MVP brief 和 Harness 状态一致。
- anti_cheat: 不通过跳过测试、隐藏 Gitee 问题为 GitHub 通过、或把 PG/AI 实现偷塞进 MS5 来制造完成状态。

## Developer Decision Boundary

- 可以自动处理 GitHub CI 配置、文档和低风险状态刷新。
- 推送 GitHub 可在用户当前授权范围内执行；若需要新凭据或远端交互失败，handback。
- Gitee 推送、托管平台选择、付费服务、生产 secret 配置和数据库迁移需要用户决策。
